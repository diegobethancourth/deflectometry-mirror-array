Design — overview

From test object to a complete bench, one dependent step at a time.

What this track produces

The Design track turns a test object into a complete bench: field of view, fringe, camera, lens, mounting height, aperture and error budget. The steps depend on each other, so they are followed in order. Each step uses only quantities fixed in the steps before it.

  • One working bench. All Design pages share one set of values (the "working bench"). Choose a starting bench on D0; every later page reads it, and a value changed on any page is updated everywhere.
  • The yellow bar under the menu on each Design page shows which bench is in use. To switch to another bench, use D0.
  • D6 collects the results of every step on one printable page.
