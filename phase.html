L3 · Phase retrieval methods compared

N-step phase shifting · Fourier-transform method · sheared Fourier (SMOTS).

Learning objective
Compare the three ways of decoding a fringe: N-step phase shifting, the Fourier-transform method and the sheared Fourier analysis of SMOTS. Know what each needs (frames), what it returns (a map or one number) and where each fails.

Check yourself
1. Choose "uniform shift". Why does SMOTS recover it exactly with one frame pair?

A uniform shift is a single phase ψ for the whole aperture. The Fourier ratio S/F at the carrier equals eiψ − 1, which contains ψ and nothing else (Choi et al., Eqs. 1–4).

2. Choose "local bump" and narrow it. Which method follows it, and why does the Fourier-transform method smooth it?

Phase shifting is pixel-wise, so it follows any shape. The Fourier-transform method keeps only a band of frequencies around the carrier, so features narrower than about Ns/(2·window) samples are smoothed. SMOTS returns only the average.

3. Raise the amplitude above π with unwrapping off. What happens?

Every method returns φ modulo 2π, so the curve jumps. Unwrapping removes the jumps where the phase changes slowly between samples; SMOTS cannot be unwrapped from a single number, which is why Choi et al. add a second fringe frequency (Sec. 3.2).

4. Why does phase shifting need the scene to stay still while N frames are recorded?

The N frames are combined pixel by pixel assuming only the displayed shift changed between them. Any motion adds an unknown phase and biases the result — a reason SMOTS, with one measured frame, suits real-time alignment.
