3Save, load or print (optional)
The working bench is stored only in this browser. Save it as a file when you want to:
  1. keep a copy, or continue on another computer;
  2. hand it in with a report or an assignment, so the numbers can be reproduced;
  3. give it to a lab partner, who loads it and sees exactly your bench.
The file (deflectometry-bench.json) contains every value on this page and the camera candidates entered in D3 — nothing else.
