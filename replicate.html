Replicate — overview

From a published paper to working code and a real bench.

What this track is

A case study follows one published experiment from the paper to working code and a real bench. The first case study is SMOTS (Choi et al., Proc. SPIE 10377, 2017), the method behind the ASU SOLAR mirror-array research.

  • Before starting: L1 and L3 of the Learn track explain the physics and the phase retrieval used here.
  • Order: read the paper summary (R1), run the notebook (R2), use the simulator (R3), then see how a real bench was designed for it (R4).
