Learn — overview

Five modules, in order, from reflection to calibration.

What this track teaches

Five modules build deflectometry from first principles, for any method — not only SMOTS. They are meant to be followed in order: each one uses an idea from the module before it.

  • Background assumed: trigonometry and the idea of a sine wave; Fourier transforms are introduced where they are needed (L3).
  • Every module has the same parts: a learning objective, numbered figures, the equations with live numbers, an interactive model, key ideas, and "Check yourself" questions whose answers open on click.
  • Next → at the bottom of each module leads to the next one; the last leads to the Design track.
